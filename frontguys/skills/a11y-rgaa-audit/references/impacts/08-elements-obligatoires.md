# Thématique 8 — Éléments obligatoires

## Validité du code source

Un code HTML bien structuré peut être nécessaire aux technologies d'assistance pour restituer le contenu et permettre les interactions avec la page. Si le code comporte des erreurs (comme des balises mal écrites), certaines fonctionnalités risquent d'être inutilisables (comme la navigation de lien en lien, par exemple).

**Critères RGAA associés :**
- [8.1](./../rgaa/08-elements-obligatoires.md) — Chaque page web est-elle définie par un type de document ?
- [8.2](./../rgaa/08-elements-obligatoires.md) — Pour chaque page web, le code source généré est-il valide selon le type de document spécifié ?

---

## Identification de la langue principale et des changements de langue

Certaines personnes présentant des troubles de la lecture (comme la dyslexie ou l'illettrisme) utilisent des lecteurs vocaux qui peuvent être moins efficaces si les changements de langue ne sont pas indiqués. Les personnes aveugles ou malvoyantes qui utilisent un lecteur d'écran peuvent rencontrer d'importantes difficultés à comprendre les textes lus dans une langue qui n'est pas la bonne.

**Critères RGAA associés :**
- [8.3](./../rgaa/08-elements-obligatoires.md) — Dans chaque page web, la langue par défaut est-elle présente ?
- [8.4](./../rgaa/08-elements-obligatoires.md) — Pour chaque page web ayant une langue par défaut, le code de langue est-il pertinent ?
- [8.7](./../rgaa/08-elements-obligatoires.md) — Dans chaque page web, chaque changement de langue est-il indiqué dans le code source (hors cas particuliers) ?
- [8.8](./../rgaa/08-elements-obligatoires.md) — Dans chaque page web, le code de langue de chaque changement de langue est-il valide et pertinent ?
- [8.10](./../rgaa/08-elements-obligatoires.md) — Dans chaque page web, les changements du sens de lecture sont-ils signalés ?

---

## Présence et pertinence d'un titre de page

Le titre de page est la première information restituée par les technologies d'assistance. Il est utilisé dans l'historique de navigation, la liste des onglets ouverts ou lors de la mise en favoris. Les personnes aveugles ou malvoyantes et les personnes déficientes mentales ou cognitives peuvent rencontrer d'importantes difficultés à identifier ou retrouver une page si le titre est absent ou peu pertinent.

**Critères RGAA associés :**
- [8.5](./../rgaa/08-elements-obligatoires.md) — Chaque page web a-t-elle un titre de page ?
- [8.6](./../rgaa/08-elements-obligatoires.md) — Pour chaque page web ayant un titre de page, ce titre est-il pertinent ?

---

## Utilisation des balises à bon escient

Un code HTML sémantique est nécessaire aux technologies d'assistance pour restituer le contenu et permettre les interactions avec la page. Si les balises ne sont pas utilisées pour leur sens, la restitution peut être difficilement compréhensible et certaines fonctionnalités risquent d'être inutilisables.

**Critère RGAA associé :**
- [8.9](./../rgaa/08-elements-obligatoires.md) — Dans chaque page web, les balises ne doivent pas être utilisées uniquement à des fins de présentation. Cette règle est-elle respectée ?
